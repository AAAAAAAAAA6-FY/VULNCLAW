  * {{ if not .Values.existingSecret }}当前未配置 existingSecret：容器将以"能力降级"方式启动（同 compose 的 .env 可选语义）。{{ else }}已引用 Secret: {{ .Values.existingSecret }}（键名须与环境变量同名）。{{ end }}

  * OOB 回调服务：worker 侧通过 OOB_INTERACTSH_SERVER={{ .Values.env.OOB_INTERACTSH_SERVER | quote }} 注入
    （留空则 OOB 盲打不可用，带内判定不受影响）。

扩容：
  helm upgrade {{ .Release.Name }} . -n {{ .Release.Namespace }} --set worker.replicas=4
